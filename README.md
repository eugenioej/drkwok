# Riverside Smiles Astro Homepage

Modern Astro + Tailwind rebuild for the Riverside Smiles homepage.

## Local Development

```bash
npm install
npm run dev
```

Local URL:

```text
http://127.0.0.1:4321/
```

## Production Build

```bash
npm run build
```

The static site is generated in `dist/`.

## Cloudflare Pages

Recommended settings:

- Framework preset: `Astro`
- Build command: `npm run build`
- Build output directory: `dist`
- Node version: `20.19.0` or newer

The homepage currently uses local assets copied from the existing Riverside Smiles site. Secondary pages, richer SEO content, online booking, and final image swaps can be added next.
